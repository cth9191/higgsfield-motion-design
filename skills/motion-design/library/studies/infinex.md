## Review and failures

Local asset finish received positive feedback. The V05 phone/type movement is still a candidate, and outgoing blur was explicitly rejected. A6.70s comparison shows sharp rectangular blur boundaries around the heading and subtitle words. The source spreads smoothly around the letters. The library retains this as a failure example, not an approved effect.

V06 proposes auditing repeated-edge behavior and using a padded full-frame text precomposition if needed. No corrected render exists in this snapshot. The exact cause must be established by an isolated native test; increasing blur amount alone does not repair a constrained effect boundary.

The local reconstruction reaches 8.8 seconds. Later fingerprint, orbit and closing passages remain reference studies in that revised build. Neither a successful export nor mathematically smooth controls constitute creative approval.

## Adaptation and evidence boundaries

Use a persistent hero when it explains a meaningful connection. Separate local arrival cadence from settle duration. Give outgoing focus loss time to be visible before opacity removes it. Refit settings for new typography, scale and duration; preserve the useful relationships rather than every number.
