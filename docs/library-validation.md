# Shot library pilot validation

Recorded September 16, 2026. Updated scope: one Infinex study with three shot entries and two supporting details, alongside the existing ten film presets. The initial pilot had only one combined shot plus blur/lighting; the opening and question now have their own pages, and all three shots have expanded inline technical sections.

## Package and delivery

- Both builders pass: ten unchanged source-prompt hashes and five valid study records. Generated output is deterministic.
- Twenty-two standard-library tests cover creative/technical retrieval, retained rejected results, overlapping events, excerpt boundaries, relationship and preview consistency, formula/table evidence, provenance, path portability, missing media, native download names, explicit asset delivery and video byte ranges.
- Skill frontmatter and JavaScript syntax checks pass.
- CI runs both builders, the catalog/server tests and a generated-file drift check. These are local results; they do not claim a hosted CI run has passed.

## Viewer

A fresh headless Chromium session verified five playable 1280×720 reference excerpts, playback and source-frame seeking, inspiration/technical tabs and keyboard switching, native evidence links, rejected blur evidence, search/reset/empty state, combined filters, and readable records with all local media disconnected. All three shot pages expose their formulas and control tables without opening a linked script. Section navigation and horizontally scrolling code/tables were checked at desktop and 390px mobile widths. The existing ten-preset gallery still renders and builds/copies a brief-specific request. No page script errors occurred.

Desktop and 390px mobile screenshots were inspected. The mobile page has no horizontal page overflow; its timeline, wide tables and code intentionally scroll within their own regions. Fifty-three explicitly mapped local files exist, including five representative stills extracted from documented source frames; poster selection leaves playback starting at excerpt time zero. The public package contains no source video, poster image or native project payloads, and works without that private manifest.

## Creative limits

The integration adds browsing and retrieval; it performs no new AE/Blender render or full motion/audio review. Native links point to versioned evidence, not universal ready-to-run templates. Phone and lighting records remain mixed; the V05 outgoing blur remains rejected and V06 remains an unrendered proposal. The other studies in the proposed larger library are not completed by this pilot.
